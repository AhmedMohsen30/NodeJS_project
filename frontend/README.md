# واجهة CareClinic

واجهة React تعرض العيادات والتخصصات الموجودة فعلًا في MongoDB عبر API الباك إند.

## التشغيل المحلي

افتح Terminal أول في جذر المشروع وشغّل الباك إند:

```bash
npm ci
npm start
```

افتح Terminal ثاني داخل `frontend` وشغّل الواجهة:

```bash
cd frontend
npm ci
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، وغالبًا `http://localhost:5173`.

الواجهة تطلب `/api/clinics` و`/api/specialties`. إعداد `vite.config.js` يوجّه طلبات `/api` من منفذ Vite إلى الباك إند على `localhost:5000` أثناء التطوير. لو ظهر تنبيه اتصال، تأكد أن الباك إند يعمل على منفذ 5000.

ظهور رسالة «مفيش عيادات» مع عدم وجود خطأ يعني أن الاتصال يعمل لكن قاعدة البيانات لا تحتوي عيادات بعد. لا تضع رابط MongoDB أو كلمة السر في ملفات الواجهة؛ `.env` الخاص بالباك إند فقط هو الذي يقرأها.

عند نشر الواجهة، يجب توجيه `/api` إلى عنوان الباك إند في إعدادات الاستضافة؛ إعداد Vite للـproxy يعمل أثناء التطوير المحلي فقط.
