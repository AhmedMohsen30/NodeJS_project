# واجهة CareClinic

واجهة React تعرض بيانات MongoDB من الباك إند: العيادات والتخصصات والأطباء والمواعيد، وتسمح بالتسجيل والحجز وإدارة الحجوزات.

## التشغيل المحلي

افتح Terminal أول في جذر المشروع وشغّل الباك إند:

```bash
npm ci
npm start
```

افتح Terminal ثاني داخل `frontend` وشغّل الواجهة:

```bash
cd frontend
npm ci
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، وغالبًا `http://localhost:5173`.

الواجهة تستخدم مسارات `/api/clinics` و`/api/specialties` و`/api/doctors` و`/api/auth` و`/api/appointments`. إعداد `vite.config.js` يوجّه طلبات `/api` من منفذ Vite إلى الباك إند على `localhost:5000` أثناء التطوير. لو ظهر خطأ اتصال، تأكد أن الباك إند يعمل على منفذ 5000.

## تجربة رحلة الحجز

1. افتح «دخول» وأنشئ حسابًا. كود التفعيل يصل لبريد المستخدم عندما يكون `EMAIL_MODE=smtp` مضبوطًا في `.env` الخاص بالباك إند.
2. افتح «تفعيل البريد»، ثم سجّل الدخول.
3. افتح «الأطباء والحجز»، اختر طبيبًا ويومًا وميعادًا، واكتب بيانات المريض.
4. أكّد الدفع التجريبي، ثم افتح «مواعيدي» لعرض الحجز أو إلغائه.

تأكيد الدفع يغيّر حالة الحجز في MongoDB فقط؛ لا توجد بوابة دفع حقيقية. رمز الدخول محفوظ في جلسة المتصفح الحالية، ويُحذف عند تسجيل الخروج أو إغلاق الجلسة.

ظهور رسالة «مفيش عيادات» مع عدم وجود خطأ يعني أن الاتصال يعمل لكن قاعدة البيانات لا تحتوي عيادات بعد. لا تضع رابط MongoDB أو كلمة السر في ملفات الواجهة؛ `.env` الخاص بالباك إند فقط هو الذي يقرأها.

عند نشر الواجهة، يجب توجيه `/api` إلى عنوان الباك إند في إعدادات الاستضافة؛ إعداد Vite للـproxy يعمل أثناء التطوير المحلي فقط.
